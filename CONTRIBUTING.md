# Contributing / Contribuire

Issues and pull requests are welcome. Include OpenWrt release, Homarr version and anonymized API shape, but **never** passwords, tokens, private device identifiers or raw firewall logs. Keep both English and Italian docs aligned. Test Python compilation, JSON parsing and the repository hygiene check before opening a PR. Do not add cloud telemetry or automatic port forwarding. Prefer backwards-compatible additive changes to the persisted SQLite schema.

Segnalazioni e contributi sono benvenuti. Descrivi le versioni utilizzate, riproduci il problema con dati fittizi, mantieni aggiornate entrambe le guide e non allegare credenziali o database reali.
